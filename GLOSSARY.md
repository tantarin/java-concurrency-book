# Словарь терминов

В главах английский термин при первом появлении сопровождается русским значением. Имена классов и методов Java API не переводятся: например, `ExecutorService`, `Future` и `compute()` остаются такими же, как в коде и документации.

| English term | Русское значение |
|---|---|
| atomicity | атомарность, неделимость операции |
| carrier thread | поток-носитель для virtual thread |
| callback | обратный вызов |
| blocking queue | блокирующая очередь |
| busy waiting | активное ожидание с постоянной проверкой условия |
| backpressure | обратное давление, ограничение скорости производителей |
| check-then-act | проверить, затем действовать |
| Callable | задача, возвращающая результат и допускающая исключение |
| checked exception | проверяемое исключение |
| Code Cache | кеш скомпилированного кода |
| concurrent collection | конкурентная коллекция |
| consumer | потребитель данных или задач |
| coordination | координация работы потоков |
| copy-on-write | копирование при записи |
| data race | гонка данных |
| divide and conquer | разделяй и властвуй: разбиение задачи и объединение результатов |
| executor | исполнитель задач |
| Executor Framework | фреймворк исполнителей задач |
| ExecutorService | сервис выполнения задач с результатами и жизненным циклом |
| Future | будущий результат асинхронной операции |
| fork | отделить и запланировать подзадачу |
| fail-fast iterator | итератор, быстро обнаруживающий структурное изменение |
| fan-out | разветвление одной операции на несколько параллельных вызовов |
| factory method | фабричный метод, создающий настроенный объект |
| guarded block | блок, выполняемый только после выполнения защищающего условия |
| lifecycle | жизненный цикл объекта или сервиса |
| granularity | гранулярность, размер отдельной подзадачи |
| latency | задержка выполнения одной операции |
| mounting | назначение virtual thread на carrier thread |
| happens-before | отношение «предшествует» |
| heap | куча, общая область памяти объектов |
| immutable | неизменяемый |
| interruption | прерывание |
| Java Language Specification / JLS | спецификация языка Java |
| Java Memory Model / JMM | модель памяти Java |
| join | дождаться подзадачи и получить её результат |
| lock | блокировка; также говорят «замок» |
| Metaspace | область метаданных классов |
| mutex / mutual exclusion | взаимное исключение |
| native memory | нативная память вне Java heap |
| platform thread | платформенный поток |
| producer | производитель данных или задач |
| pinning | закрепление virtual thread за carrier thread во время блокировки |
| race condition | состояние гонки |
| read-modify-write | прочитать, изменить, записать |
| rejection policy | политика отклонения задачи перегруженным executor |
| Runnable | задача без возвращаемого результата |
| stack | стек вызовов потока |
| stack frame | кадр стека одного вызова метода |
| spurious wakeup | ложное пробуждение без подходящего уведомления |
| thread | поток выполнения |
| thread factory | фабрика создания и настройки потоков |
| thread pool | пул потоков, переиспользуемый набор рабочих потоков |
| threshold | порог, после которого задачу перестают дробить |
| thread-per-task | отдельный поток для каждой задачи |
| throughput | пропускная способность, число завершённых операций за время |
| unmounting | освобождение carrier thread виртуальным потоком |
| virtual thread | виртуальный поток |
| visibility | видимость изменений между потоками |
| wait set | набор потоков, ожидающих на мониторе объекта |
| weakly consistent iterator | слабо согласованный итератор |
| worker thread | рабочий поток, выполняющий задачи из очереди |
| work stealing | перехват работы свободным worker у занятого |

Русский перевод помогает понять смысл, но в документации и коде важно узнавать английскую форму: именно она используется в JLS, Java API и сообщениях JVM.
